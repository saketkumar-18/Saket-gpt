# SaketGPT

Your own ChatGPT-style AI assistant — multi-thread, model-agnostic, voice-enabled, and free to run.

## Features

- 🧵 **Multi-thread chat** — new threads, rename, archive, delete, search, auto-generated titles
- 💾 **Local persistence** — threads and messages survive reloads via localStorage (zero database; swap in Postgres or assistant-ui cloud with one adapter)
- 🎨 **Premium UI** — clean light/dark/system themes, gradient user bubbles, glassy composer with focus glow, animated welcome hero with quick-prompt cards, collapsible sidebar, custom scrollbars, reduced-motion support
- 🔌 **Model-agnostic** — any OpenAI-compatible endpoint (tokenharbor, b.ai, OpenAI, OpenRouter, Groq, Ollama, vLLM…). Allow-list enforced server-side; picker hydrates from `GET /api/models`
- 🎙️ **Voice** — microphone dictation and read-aloud responses (Web Speech API)
- 🧠 **Reasoning display** — chain-of-thought summaries stream in a collapsible block
- 🛠️ **Built-in tools** — exact calculator and timezone-aware clock; the model calls them instead of guessing
- ✍️ **Custom instructions** — per-user system prompt from the header, persisted locally
- 🔁 **Edit, branch, retry, copy** — full message lifecycle from assistant-ui
- ➡️ **Follow-up suggestions** — next-prompt chips generated by the model after each answer
- ⏱️ **Rate limiting** — per-IP sliding window on the chat route
- 🌗 **Light/dark/system theme**

## Quick start

```bash
git clone https://github.com/saketkumar-18/Saket-gpt.git
cd Saket-gpt
npm install
cp .env.example .env.local   # add your LLM_API_KEY
npm run dev
```

Open http://localhost:3000.

## Configuration

All in `.env.local`:

| Variable         | Default              | Meaning                                        |
| ---------------- | -------------------- | ---------------------------------------------- |
| `LLM_BASE_URL`   | `https://tokenharbor.ai/v1` | Any OpenAI-compatible `/v1/chat/completions` base |
| `LLM_API_KEY`    | —                    | Provider key (falls back to `OPENAI_API_KEY`)  |
| `CHAT_MODELS`    | `mimo-v2.5:free,deepseek-v4-flash:free,mimo-v2.6-flash:free` | Comma-separated allow-list shown in the picker |

Local LLMs work too — start Ollama and set
`LLM_BASE_URL=http://localhost:11434/v1`, `LLM_API_KEY=*** `CHAT_MODELS=llama3.2`.

## Architecture

```
app/
  api/chat/route.ts        # AI SDK v7 streamText + server tools + rate limit
  api/models/route.ts      # model allow-list for the picker
  api/suggestions/route.ts # follow-up prompt generation
  assistant.tsx            # runtime wiring (thread list + chat transport)
components/
  assistant-ui/elements/   # thread, thread-list, sidebar, reasoning, tools UI
  chat-header.tsx          # model picker + custom instructions + theme
lib/
  models.ts                # system prompt + allow-list (single source)
  thread-storage.ts        # localStorage RemoteThreadListAdapter
  store.ts                 # zustand settings (model, instructions)
  rate-limit.ts            # in-memory sliding window
```

Persistence uses assistant-ui's `RemoteThreadListAdapter` contract — to move to a real database, implement the same interface against your API (see [docs](https://www.assistant-ui.com/docs/integrations/persistence/custom-adapter)).
